# DeepSeek 网页自动翻译

[仓库主页](https://github.com/sunzhaocn/deepseek-web-translator) · [安装 / 下载单文件脚本](https://raw.githubusercontent.com/sunzhaocn/deepseek-web-translator/main/deepseek-web-translator.user.js)

当前版本 **1.9.1**。安装文件：`deepseek-web-translator.user.js`。油猴脚本运行时不需要 Node.js、Python 或自建服务器。

## 安装与更新

本仓库只包含单文件脚本与使用说明，运行时无需安装 Node.js、Python 或依赖包。

1. 浏览器安装 [Tampermonkey（油猴）](https://www.tampermonkey.net/)，并允许用户脚本运行。
2. 点击 **[安装 / 获取最新版脚本](https://raw.githubusercontent.com/sunzhaocn/deepseek-web-translator/main/deepseek-web-translator.user.js)**，在油猴安装页确认安装。
3. 如果浏览器直接显示源码，请在油猴中“添加新脚本”，用全部源码替换默认内容并保存。升级时打开原脚本覆盖保存，避免启用两个副本。
4. 刷新需要翻译的网页，点右下角“译 · 简体中文”，填写自己的 [DeepSeek API Key](https://platform.deepseek.com/)，选择目标语言，点击“保存并翻译”。已有 Key 留空会保留。

本次保留 Key、目标语言、模型、站点开关及其他设置。1.9.1 继续复用符合保护校验的 1.9.0 完整译文缓存。新版名称政策与旧版强制音译不同，**旧提示词版本的译文不再复用**；旧缓存无需手工清除，访问过的内容会按新规则重新翻译一次，再继续使用新缓存。

## 1.9.1：修复刷视频时反复失败

- 简体中文目标下，纯中文内容与已保护的名称/数据在本地跳过；UP、UID、ID、IP、BGM、MV、PV、OST、FPS 等明确标记保留，减少视频页面无意义的请求。
- 名称保留信息是可选字段。错误声明会被忽略，保留原文和译文中精确存在的有效名字；不会仅因这项辅助信息错误而拒绝整批译文。公式、数值和占位标记仍严格校验。
- 格式失败后将各条内容分开重试，避免一个难译标题反复拖住其他内容；网络故障与限流继续按原有退避处理。手动重试也改为逐条提交。
- 主翻译已产生含中文的可用草稿、后续补译耗尽时，保留通过专业片段校验的草稿，并显示“已保留可用译文，部分外文待补译”。它仍算待处理项，可点“重试失败内容”；不把草稿保存为完整的持久缓存。同一页面重建相同内容可以暂时复用，避免反复闪回原文。
- 视频卡片被移除、网站复用文字节点或改成原生中文后，过期失败不继续计数。原文更新仍优先于旧响应。
- 扫描尚未完成时不会提前显示“已翻译”。

独立浏览器检查中，B站首页实际可加载；71 个可见文字片段中只需提交 3 个含外文的片段，模拟接口下无脚本运行错误。抖音返回验证码中间页，未完成实际信息流验证；不将验证码页没有报错视为抖音刷视频验证通过。站点检查使用假 API，不代表真实 DeepSeek 服务成功率。

## 1.9.0 的变化

- **保留名字。** 人名、用户名、模型名、品牌、组织、产品身份、软件名和拉丁学名要求保留原拼写，翻译周围说明。取消旧版“所有名称必须汉字音译”的主翻译和补译指令。
- **补译区分名字与漏译。** 模型可以在同一次响应中声明精确保留的专名；脚本仅接受在原文与译文中都精确存在的名字，并随整句缓存保存。后续补译不会把这些名字再次音译。不会仅凭首字母大写跳过普通按钮、标题或说明。
- **自定义保留词。** 面板“始终保留原文的名字 / 术语”每行填写一个，最多 100 项，每项不超过 120 字符，区分大小写。已识别的模型名、自定义名称和明确的作者/用户名字段优先本地保护。修改词表后点击“保存并翻译”，旧词表缓存不会混用。
- **科学与历史内容更严格。** 提示词明确保留否定、推测、概率、相关与因果的区别、学科术语、历史年代与原作者表述；不擅自换算单位、历法或补充事实。不会在科学、医学、历史说明中添加梗解释。采样温度调为 0。
- **数值与符号精确保留。** 已识别的编号、分子式、数值、百分比、科学计数法、单位、不确定度、BC/AD/BCE/CE 和数字日期通过占位标记保护。标记丢失、重复或数值被拼改的响应不提交。长文本切分避免拆开完整受保护片段，并用一次扫描加游标处理长文。
- **短词按语境缓存。** 被内联标签拆开的文字可携带最多约 600 字符的可见段落原文。原文不超过 80 字符且有局部语境时，任务与缓存一并按语境区分，避免将金属语境中的 lead 复用到“带领”语境。相同语境仍可复用；周围原文变化会使旧结果失效。补译片段不再充当跨语境通用词典。
- **修复更多漏译。** 支持可见 SVG 图表文字、标题说明与 `foreignObject` 中的 HTML；新增 `aria-description`。CSS 将 `hidden` 元素实际显示后可以翻译，真正隐藏和 `content-visibility:hidden` 的内容不发送。动画/过渡结束、页面重新显示后会补扫。
- **修复组件内交互。** 开放 Shadow DOM 内部的悬停、焦点菜单及输入框失焦后的提示文字可触发扫描；保持输入值、焦点和选择范围。

## 日常使用

| 功能 | 行为 |
| --- | --- |
| 要显示的语言 | 支持简体中文、English、日本語等自由输入 |
| 模型名称 | 默认 deepseek-flash，可填写账户可用的模型 ID |
| 自动翻译 | 保存后新网页自动开始；也可按站点关闭 |
| 流式显示 | 完整收到并通过格式检查的一条先显示；整批通过后保存缓存 |
| 补译普通漏译词 | 默认开启；主要用于中文目标，不强制音译专名 |
| 暂停 / 继续 | 暂停取消未完成请求，保留完成的译文 |
| 恢复原文 | 恢复脚本改过且网站没有再次更新的文字，并暂停 |
| 重试失败内容 | 只重试本页失败项，其他内容继续工作 |
| 清除本站缓存 | 清除本站各语言/模型的保存结果，保留已显示文字并暂停 |
| 测试连接 | 只发送 Hello，不发送网页内容，也不自动保存设置 |
| 删除 Key | 清除脚本保存的 Key 并停止当前页请求 |

## 页面兼容与速度

按文字节点原位替换，不重建网站 DOM，不替换链接、事件绑定、控件 ID、输入值或 SVG 几何属性。支持动态新增内容、单页应用路由、滚动容器、悬停菜单、开放 Shadow DOM 和可执行脚本的 iframe。同源 iframe 共享父引擎；跨域 iframe 由油猴分别注入，主页面统一暂停、恢复和设置。

可翻译 `title`、`alt`、`placeholder`、`aria-label`、`aria-description`、`label` 和原生下拉选项；隐式 option value 会保留原提交值，不改变选择或触发 change。编辑区、代码、MathJax、KaTeX、MathML 和明确的数学区域保持原样。用户启用翻译后，普通文字不会仅因网站的 `.notranslate` 或 `translate="no"` 而漏扫；这些网站属性本身不修改。

缓存命中即时回填，有界快速回填每次 MutationObserver 回调最多检查 200 个节点，其余分帧扫描。请求按小批次自动并发，可见内容优先，完成即补位。正常失败最多自动重试 2 次；限流/服务繁忙按退避与 Retry-After 等待，不对整个页面反复重启。

流式不支持、停滞或格式错误时回退普通 JSON。请求有 60 秒总超时，流式读取后有 20 秒无数据超时。暂停、改语言、网站更新文字后，旧响应不再覆盖新内容。输入时约等待 220ms 停顿再发新请求，已缓存文字仍可复用。

**首次新内容仍取决于网络与 DeepSeek 响应时间，不能保证零延迟。** 自动并发不代表绕过服务端限流。

## 支持边界

这是通用网页翻译增强，不保证所有网站、所有专名和所有学科都能百分之百识别。自定义保留词可用于特别重要、陌生或自定义的名称；未被本地规则识别的专名仍依赖模型判断。保留声明验证的是精确来源和拼写，不是专名语义的数学证明。

格式规则可以保护已识别的 `BRCA1`、`NM_007294.4`、`(NH4)2SO4`、`SO₄²⁻`、`5 mg`、`37 °C`、`20 mg/kg/day`、`6.022e23`、`44 BCE` 等，但不会验证原文科学正确性，也无法保证所有化学命名、复杂复合单位、学名和论文译法正确。提示词与低温采样是质量约束，不是事实核查。

跨标签长句仍逐节点写回，局部上下文有长度和结构限制；非段落容器或缺乏语境的孤立词仍可能歧义。网页框架持续重绘时可能短暂回跳。

图片里的字、视频画面、Canvas、PDF 阅读器、封闭 Shadow DOM 不支持直接替换。浏览器内部页、扩展商店以及完全禁止脚本注入的文档受浏览器限制。iframe 必须允许油猴在相应文档执行；不绕过同源策略或站点沙箱。

## 数据与费用

翻译会将待译网页文字、必要的可见局部语境及补译草稿发送至 DeepSeek，按用户 API 账户计费。脚本不翻译用户编辑区和输入值；请自行选择需要翻译的网页。

Key 保存在 `GM_setValue` 油猴专用存储，不写入网站 localStorage 或页面 HTML。设置面板使用封闭 Shadow DOM。跨 iframe 控制通过油猴专用存储通道，不在网页 postMessage 中传递 Key 或译文。油猴存储不是加密保险库。

原文、译文、保留名称及短片段必要语境也会缓存于油猴存储。按网站来源、语言、模型、梗设置、名称词表、提示词版本及必要上下文隔离；每来源最多约 3000 条、200 万字符，超限淘汰较早条目。可以使用“清除本站缓存”删除。
